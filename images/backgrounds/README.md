# Фоны главной страницы

Сюда кладутся репродукции натюрмортов мясных лавок (или любые изображения), которые циклически
сменяются в шапке главной страницы. Отображаются поверх автоматически затемняющей подложки, чтобы
текст оставался читаемым.

- Поддерживаемые расширения: `.jpg`, `.jpeg`, `.png`, `.webp`, `.gif`, `.avif`.
- Имена файлов — произвольные.
- Список отдаёт `GET /api/catalog/backgrounds`, файл — `GET /api/catalog/backgrounds/{имя}`.
- Если папка пуста, главная использует встроенные CSS-градиенты.

В Docker каталог `images/` монтируется в контейнер как `/images`, поэтому достаточно положить файлы
на хосте — перезапуск не требуется (обновление страницы подхватит список).
