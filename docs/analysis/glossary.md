# Глоссарий

Единый словарь терминов предметной области и технических понятий прототипа. Используется в
требованиях, вариантах использования, процессах и спецификации.

## Предметная область

| Термин | Определение |
| --- | --- |
| **Колбасный цех** | заказное производство при мясокомбинате; выпускает готовые композиции и изделия по рецепту клиента |
| **Колбасный торт** | художественная композиция из готовой продукции, подаётся как торт |
| **Мясная лавка** | раздел каталога с композициями из готовых колбасных изделий (16 позиций) |
| **Арт-объект** | изделие, форма которого повторяет знакомый объект (самолёт, корабль, замок и т. п.) |
| **SKU (артикул)** | уникальный код товара, например `MS-001`, `AO-016`; используется и как имя файла изображения |
| **Изделие по рецепту** | товар, собранный клиентом в конструкторе; хранится как конфигурация |
| **Конфигурация** | сохранённый набор выбранных опций (тип, технология, сырьё, форма, добавки, специи) с ценой |
| **Опция** | вариант выбора внутри группы конструктора с подсказкой и надбавкой к цене |
| **Надбавка (price_delta)** | прибавка к базовой цене изделия за выбранную опцию, в рублях |
| **Уровень лояльности** | ступень программы лояльности с порогом баллов и скидкой |
| **Баллы** | вознаграждение за покупки; влияют на уровень, начисляются после оплаты |
| **Акция** | временное изменение условий: скидка или множитель начисления баллов |
| **Охват акции** | область действия: конкретный товар, категория или все товары |
| **Множитель баллов** | коэффициент начисления баллов в акции |
| **Статус заказа** | этап обработки: новый → подтверждён → в производстве → упаковка → готов → отправлен → завершён (или отменён) |
| **Демо-оплата** | эмуляция оплаты: заказ помечается оплаченным и переводятся баллы, реальных платежей нет |
| **Место доставки** | координаты (широта/долгота), сохранённые клиентом на карте OpenStreetMap |
| **Раздел** | верхний уровень каталога: «Мясная лавка» или «Арт-объекты» (`meat_shop` / `art_object`) |
| **Категория** | подгруппа внутри раздела (например, «Транспорт», «Провокации») |
| **Промпт изображения** | текст для генерации изображения товара; хранится в товаре и в `docs/product-prompts.md` |

## Роли

| Термин | Определение |
| --- | --- |
| **Клиент** (`client`) | покупатель: каталог, конструктор, корзина, заказы, баллы |
| **Технолог производства** (`technologist`) | справочники и цены, обработка заказов, выгрузка и статусы |
| **Бизнес-аналитик** (`analyst`) | дашборды и управление акциями |
| **Администратор сервиса** (`admin`) | пользователи, роли, клиенты, корректировка баллов |

## Технические понятия

| Термин | Определение |
| --- | --- |
| **SPA** | одностраничное приложение (React), общается с API по HTTP/JSON |
| **JWT** | подписанный токен доступа; передаётся в заголовке `Authorization: Bearer` |
| **Роль** | атрибут пользователя, определяющий доступ; проверяется на сервере |
| **Заглушка (SVG)** | изображение, показываемое, если для товара нет реального файла |
| **WebP** | сжатый формат изображений, приоритетный при отдаче товаров |
| **Seed (сидирование)** | наполнение демо-данными при первом запуске |
| **Миграция** | лёгкое добавление недостающих столбцов SQLite при старте без потери данных |
| **ERD** | диаграмма «сущность–связь» (в `docs/specification.md`) |
| **Use Case** | вариант использования (в `docs/analysis/use-cases.md`) |
| **BPMN-подобная схема** | блок-схема бизнес-процесса (в `docs/analysis/processes.md`) |
| **Матрица трассируемости** | связь требований с реализацией и тестами (`docs/analysis/requirements.md`) |
| **TTS** | синтез речи (Yandex SpeechKit) для демо-тура |
| **Демо-тур** | автоматический проход по интерфейсу с озвучкой и видео (`demo/`) |
