# Демо-доступы

Прототип поставляется с предзасеянными аккаунтами всех ролей. Пароли демонстрационные.

| Роль | Email | Пароль |
| --- | --- | --- |
| Клиент | `client@kolbaska.ru` | `client123` |
| Клиент (гурман) | `gourmet@kolbaska.ru` | `client123` |
| Технолог производства | `technolog@kolbaska.ru` | `techno123` |
| Бизнес-аналитик | `analyst@kolbaska.ru` | `analyst123` |
| Администратор сервиса | `admin@kolbaska.ru` | `admin123` |

На странице входа есть кнопки быстрого входа под каждую роль.

Регистрация новых клиентов работает через интерфейс или `POST /api/auth/register`.
