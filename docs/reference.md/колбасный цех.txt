Твоя задача- разработать продающий прототип пользовательского интерфейса программного обеспечения для поддержки стандартного интернет-магазина при оригинальном производстве.
Заказчик - владелец крупного мясокомбината, производящего широкий ассортимент колбасных изделий. Заказчик хочет открыть при своем мясокомбинате новый цех для производства колбасных изделий на заказ. Предусмотрено два направления работы цеха:
- Для производства оригинальных "колбасных тортов", скомпонованных из обычной продукции мясокомбината.
- Для производства колбасных изделий в малых объемах по рецепту, составленному клиентом, и выбранной им технологии, из числа предусмотренных на комбинате.
Заказчик имеет налаженные каналы поставки любого необходимого, в том числе, экзотического сырья.
Заказчик имеет достаточно финансовых средств и квалифицированного персонала для приобретения и обслуживания любого необходимого готового технологического оборудования для нового цеха. 
Заказчик заказывает нам программное обеспечение для обслуживания продаж продукции нового цеха.
Прототип интернет-магазина НЕ ДОЛЖЕН выполнять принимать реальные платежи, выполнять реальные транзакции, автоматически отправлять заказы на производство, отслеживать логистику доставки товара клиенту. Но прототип ДОЛЖЕН показывать Заказчику, как с точки зрения пользователя ПО будут выглядеть эти операции.
В прототипе должен быть предусмотрен пользовательский интерфейс для следующих категорий пользователей:
- Клиенты
- Технологи производства
- Бизнес-аналитики
- Администраторы сервиса

Для клиентов должен быть предоставлен визуально привлекательный интерфейс интернет-магазин, предоставляющий доступ к следующим страницам:
- Главная страница с разделами:
   - "Для мясоедов-оригиналов"
   - "Для мясоедов-гурманов"
   - "О нас"
   - Контакты
- Регистрация в личном кабинете,
- Личный кабинет,
- Платежная страница (в продакшн эту страницу будут предоставлять партнеры)

Для Технологов производства должен быть предоставлен удобный интерфейс 
для просмотра, печати, выгрузки в файл и для отправки в производство заказов в форматах Макрдаун и JSON.
для управления списками выбора в интерфейсе клиента и ввода соответствующих цен.
Также должен быть обеспечен интерфейс отслеживания статусов выполнения заказов.

Для Бизнес-аналитиков должен быть предоставлен удобный интерфейс для просмотра статистики заказов: по ассортименту, стоимости, по сезонам и дням недели, эффекту от акций и так далее - стандартный набор метрик. Должен быть предусмотрен механизм введения временных акций 
-скидки на покупки:
  - отдельных товаров,
  - отдельных категорий товаров,
  - всех товаров.
-увеличению баллов, начисляемых за покупки:
  - отдельных товаров,
  - отдельных категорий товаров,
  - всех товаров.

- Для Администраторов сервиса должен быть предоставлен удобный интерфейс для предоставления и управления доступом в систему пользователей с ролями Технолог производства,
Бизнес-аналитик, Администратор сервиса. Также должен быть предоставлен интерфейс для контроля аккаунтов Клиентов.

Фон главной страницы должен быть сформирован из циклически сменяющихся репродукций голландских и фламандских художников эпохи возрождения, писавших натюрморты мясных лавок.
Главная страница должна 
- предоставлять выбор валюты, в которой будут показаны цены в интернет-магазине (доллары, евро, юани, рубли).
- предоставлять вход/выход/регистрацию в личный кабинет
- показывать текущие акции
- показывать информацию о скидках для клиентов, достигших определенного уровня
(младший уровень - "В начале славного пути", придумай еще уровни, например "Мясоед", "Заслуженный обжора", "Гуру мясной кулинарии" и так далее)
- переключать вкладки со страницами
   - "Для мясоедов-оригиналов"
   - "Для мясоедов-гурманов"
- предоставлять доступ к страницами
   - "О нас"
   - Контакты
- доступ к чату с ИИ-ассистентом Робертом ИИчкиным
- после входа зарегистрированного пользователя показывать ему достигнутый им уровень, количество накопленных баллов и количество баллов, которые ему нужно набрать для перехода на следующий уровень. 
   
На странице "Для мясоедов-оригиналов" должен быть представлен каталог готовых "колбасных тортов" с разделами "Мясная лавка", "Арт-объекты", с указанием состава, веса, стоимости габаритов и сроков производства. 
Для прототипа придумай по 16 оригинальных названий продукции для каждого раздела.
В разделе "Мясная лавка" должны быть представлены художественные композиции из готовых колбасных изделий, поступающих в массовое производство (не требующих приготовления). Допустимо добавление других продуктов для достижения художественной выразительности, но в меньших количествах
Среди названий продукции должны быть как романтические, ироничные  так и провокационные названия, например: "Сон мясоеда", "Любимой на завтрак", "Кошмар вегана", "Наш ответ зоозащитникам", "Кролевский бутерброт", "Бутерброт короля Артура и его 12 рыцарей", "Триумф обжорства" и так далее.
В разделе "Арт-объекты" должны быть представлены изображения колбасных изделий, форма которых представляет знакомые объекты, например: самолет, корабль, автомобиль, пиратский корабль, "НЕпряничный домик" и так далее.  
После того, как будут придуманы названия, необходимо составить детальные промпты для генерации изображений, соответствующих этому названию, и примерно оценить стоимость, вес, габариты и срок производства.  
На странице "Для мясоедов-гурманов" должны быть представлены элементы управления для выбора типа колбасного изделия, технологии его производства, сырья, добавок и специй.
Все элементы управления должны иметь всплывающие подсказки с текстом, раскрывающим роль и суть этой составляющей в колбасном производстве для не специалистов, влияние на цвет, вкус и форму.
Удобные элементы управления (ползунки или спиннеры, выпадающие списки или двухоконный интерфейс выбора, и так далее - выбери сам), придерживайся единообразия, удобства. Не перегружай форму - лучше разнести по страницам
При изменении выбора должна автоматически изменяться цена заказа. 
При выборе типа и формы должен отображаться пример готового колбасного изделия
