# Фоновая музыка для демо-ролика

Точной записи «The Right Honourable the Lady Rich, Her Galliard» (P. 43) под свободной лицензией
найти не удалось, поэтому используется другой инструментальный галльярд Джона Дауленда.

## Трек

- **Произведение:** John Dowland (1563–1626) — «The King of Denmark Galliard à5» (из Lachrimae, No. 11)
- **Файл:** `dowland-king-of-denmark-galliard.ogg`
- **Источник:** Wikimedia Commons
  <https://commons.wikimedia.org/wiki/File:John_Dowland_(1563-1626)_-_The_King_of_Denmark_Galliard_%C3%A05,_Lachrimae,_No.11_for_Treble,_Tenor_%26_Bass_Viols_with_Great_Bass_Violone_in_G.ogg>
- **Автор записи (загрузил):** Phillipwserna
- **Лицензия:** CC BY-SA 4.0 — <https://creativecommons.org/licenses/by-sa/4.0/>
- **Получено:** 2026-09-13

Само сочинение Дауленда — общественное достояние; лицензия относится к конкретной записи.

⚠️ **Attribution / Share-Alike.** При публикации ролика с этой музыкой нужно указать автора и
лицензию. Лицензия CC BY-SA требует распространять производный материал (видео) на тех же
условиях. Если это не подходит, замените трек своим файлом:

```bash
demo/.venv/bin/python demo/narrate.py --music /path/to/your-track.mp3 --duck
```

Аудиофайлы из этой папки в git не коммитятся (см. `.gitignore`).
